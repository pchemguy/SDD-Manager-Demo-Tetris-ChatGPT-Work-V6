# Browser Tetris

A single-player desktop browser Tetris project with classic gameplay, hold, ghost pieces, seven-bag randomization, wall kicks, hard drop, selectable locking policies, conditional ghost visibility, penetrator bonuses, and persistent game settings. Development is currently in documentation preparation; the game is not implemented.

See the [project brief](docs/dev/PROJECT.md) and [documentation tasks](docs/dev/DOCS_TASKS.md) for scope, accepted document versions, and progress.

Development uses [SDD Manager](SDD-MANAGER.md). See the [AI-assisted development disclosure](AI_DISCLOSURE.md).
